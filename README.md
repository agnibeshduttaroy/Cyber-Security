## 📖 About

A static website on **users' safety and security when using smartphones and social networking sites**. The main page walks through the field, and each attack type has its own linked page.

| Section | Topics |
|---|---|
| 🧭 Foundations | Introduction, vulnerabilities and attacks, information security culture |
| 🏦 Systems at risk | Financial systems, aviation, large corporations, automobiles |
| 🔐 Protection | Computer protection, security architecture, security measures, secure coding |
| 📰 Case studies | Notable attacks, Robert Morris and the first computer worm, cybercrime cases 2011–2015 |
| 🌏 Government role | International actions, national actions, India, South Korea |
| 📝 Survey | A survey form at the end of the main page |

## 👀 View it

No build step and no dependencies.

```bash
git clone https://github.com/agnibeshduttaroy/Cyber-Security.git
```

Open **`Cyber Security/Cyber Security.html`** in a browser. The attack pages open from links on it.

---

## 🗂️ Structure

```text
Cyber-Security/
└── Cyber Security/
    ├── Cyber Security.html   # Main page (start here)
    ├── Backdoor.html … Tampering.html   # One page per attack type
    └── *.jpg / *.png / *.svg # Images used across the pages
```

Keep the images next to the HTML files so they load.
